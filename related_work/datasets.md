# Temporal datasets for a cross-domain birth study

**Admission rule.** A literal node-birth experiment needs a time at which a node first becomes observable and only edges available before the prediction cutoff. For interaction datasets whose participants are present before the first recorded contact, “birth” below means *first observed activity*, not physical entry into the system. That distinction should be reported rather than concealed. Sizes and licences below were checked on 2026-11-16 against the linked providers.

## Recommended phased protocol

1. Start with OpenAlex citation and OpenAlex coauthorship to preserve a true document-driven newcomer setting with legally simple CC0 reuse.
2. Add `tgbl-wiki` and SocioPatterns as timestamped interaction stress tests, reporting first-observed activity rather than node birth.
3. Add BioGRID only as a knowledge-accumulation network with publication-time semantics.
4. Treat Common Crawl as a separate, legally reviewed web-track; it is not cleared here because a reusable content licence was not verified.

For every source, build snapshots solely from records at or before the cutoff, compute candidates from the same snapshot, and retain a data card that states the arrival proxy, deleted/late records policy, feature availability at birth, licence, and any personal-data restrictions.
